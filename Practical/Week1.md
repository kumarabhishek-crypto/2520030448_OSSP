# Practical Week 1: Basic Linux Commands

## Topic 1: Basic Linux Commands
- `pwd`: Display current working directory
- `clear`: Clear terminal screen
- `history`: Display command history
- `whoami`: Display current username
- `date`: Display current date and time
- `uname -a`: Display system information

## Topic 2: Directory Management
- `ls -l`: Display detailed file information
- `mkdir`: Create a new directory
- `cd`: Change current directory
- `rmdir`: Remove an empty directory

## Topic 3: File Management
- `touch`: Create a new empty file
- `cat`: Display file contents
- `cp`: Copy files
- `mv`: Move or rename files
- `rm`: Delete a file
- `wc`: Count lines, words, and characters

## Topic 5: C Program Compilation and Execution
- `gcc hello.c -o hello`: Compile C program
- `./hello`: Execute compiled binary
